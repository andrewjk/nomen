# Nomen

This is the Visual Studio Code language server for [Nomen](https://github.com/andrewjk/nomen).

Nomen is a statically-typed, memory managed language.

The language server provides syntax highlighting, type checking and auto-completion for `.nm` files, which look something like this:

```nomen
import System

pub func main = () {
    Console.write_line("Hello, World!")
}
```
