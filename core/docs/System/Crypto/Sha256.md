# Sha256

## `struct Sha256`

Incremental SHA-256 hasher (FIPS 180-4) — feed bytes with `update`, then `finish` for the 32-byte digest

    var hasher = Sha256()
    hasher.update("ab")
    hasher.update("c")
    const digest = hasher.finish()          // 32 raw bytes
    Console.write(Hex.encode(digest))       // "ba7816bf…15ad"

    const same = Sha256.hash("abc")         // one-shot

Digests are raw bytes in a `string`; `Text::Hex.encode` or
`Text::Base64.encode` turn them into text. `finish` resets the hasher,
so one instance can hash several messages in turn.

**Members:**

- `reset()`
- `update(view string data)`
- `finish() -> string`
- `hash(view string data) -> string`
