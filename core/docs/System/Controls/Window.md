# Window

## `class Window`

A top-level native window that hosts controls and dispatches events

**Members:**

- `show()`
- `set_title(string title)`
- `run()`
- `process_events() -> int`
- `is_visible() -> bool`
- `click_x() -> int`
- `click_y() -> int`
- `content_width() -> int`
- `content_height() -> int`
- `measure(BoxConstraints constraints) -> Size`
- `intrinsic_size() -> Size`
- `set_frame(int x, int y, int width, int height)`
