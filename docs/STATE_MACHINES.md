# Implicit State Machines

An inventory of subsystems whose behavior is driven by state that is really one
machine, but which is spread across loose sentinels, booleans, optional fields,
and sometimes a native object's truth — with the transition function duplicated
at call sites instead of encoded once.

Two layers were scanned: the runtime/app layer (`core/System/**`, `demos/**`)
and the compiler (`src/**`). Claims marked ✅ were verified directly against the
code at the time of writing; the rest come from a full inventory pass with the
cited lines. Five of the machines have since been fixed — their rows are
annotated **Fixed** with the commit — the rest stand as written.

The cross-cutting shape, in almost every entry:

> **phase = nullable handle / sentinel + one or more booleans + native truth**,
> and two of those representations can be changed independently with no check.

The one place this was done right is `Type.storage_kind` (`src/nodes/Type.ts`) —
a real discriminant. It is the in-repo exemplar to copy.

## Where to start (de-risking, not aesthetics)

Progress on the original list (2026-11-09):

1. **`Task` / spawnable lifecycle** — DONE in part (`e898e374`, `26801d04`):
   double `start`/`detach` is rejected with an explicit abort, the empty
   `Task` phase returns the zero value instead of reading address 0, and the
   stale `handle`/`done` representation is deleted. Still open: the
   explicit `empty | running | done | consumed` phase as ONE source (the
   `started` flag + zeroed handles still encode it pairwise), and resetting
   `Nursery` links on will-exit (an armed spawnable outliving its `async`
   block still writes through freed frame storage).
2. **`clone_status` + `clone_node` allow-lists** — the verified omissions are
   copied now (`e4a5d675`), and the checker's mono re-derivation re-derives
   what a clone may drop. Still open: deriving the copies from key lists so
   a newly-added stamp cannot be missed by construction.
3. **Window close latch** — the reset site is in (`47c456c1`), so a later
   red-button close reaches the app again. Still open: the pending bit is
   process-global, not per-window.
4. **`BigInt.sign`** — DONE (`e2a0401f`): the sign is maintained in every
   arithmetic path and `cmp` consumes it, canonicalized at zero.

The runtime/app layer is where these machines can crash; the compiler layer is
where they silently miscompile.
